# D · OPTIONAL REMINDERS

## Design stance
Shared Today reminder sheet with four categories, separate permission state and quiet hours.

## Key choices
- Target prototype palette, serif headline and original SVG icons.
- Mobile-first single column; four original navigation destinations.
- Day 1, 3/17 actions is an illustrative fixture, not user data.
- Clickable settings, expansions, reminder preferences and scope-specific confirmation previews.
- No localStorage, network requests, notification permission or live deployment changes.

## Trade-offs
Details expand to reveal timing and practice selectors; nothing requests real permission or schedules delivery.
