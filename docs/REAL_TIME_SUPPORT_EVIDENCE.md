## Safety and integration boundaries

The new module contains no collection code, user free text, incident narrative, diagnosis, scores, tracking, network execution or storage. It only exports `SupportTool` and `realTimeSupportTools`. Links in `references` are static bibliography URLs; including them does not request them during practice.

Content safeguards:

- Every sequence starts with a safe stationary context, away from driving, equipment and safety-critical duties. A pause never supersedes urgent protective action or operational protocols.
- Breathing is gentle, normal-sized and unforced; no breath holds. Stop and return to ordinary breathing for dizziness, breathlessness, discomfort or increased distress.
- Eyes are optional; no closed-eye requirement. Available neutral senses can substitute for missing/triggering senses; counting is not a performance target.
- No new touching is required, and no unsafe sniffing/tasting, substances, food, drink or incident reminders are prescribed. Taste already present is sufficient; substitution is equally valid.
- Each flow ends with a concrete action/orientation/needs decision. PFA does not require recounting or debriefing, and does not establish fitness for duty or transport safety.

The integrating parent UI remains responsible for the locked heading order (**What → When → How → Why → Benefits → Duration → Adaptations → Scientific References**), downward opening, one-step practice, Start/Stop/Exit, optional off-by-default audio, optional initially blank in-memory ratings and separate Connect With Support access. Do not interpret rating changes as clinical improvement. The educational/non-emergency disclaimer must be visibly rendered by that UI; the TypeScript file's comment is not a user-visible safety notice.

Reuse the app's existing Canada-labeled crisis/support boundaries; this module does not create a new resource directory, phone number or partnership. Do not infer that a linked UK NHS service is an available Canadian service or an app partner. External source links may require connectivity; none proves cold-start offline support.
